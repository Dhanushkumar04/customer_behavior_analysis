# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, sales trends, and business opportunities. The analysis involves data preparation and Exploratory Data Analysis (EDA) using Python, business-oriented SQL analysis using PostgreSQL, and interactive dashboard development using Power BI.

The objective is to transform raw customer transaction data into meaningful insights that can support data-driven business decisions.

## Dataset Description

- **Total Records:** 3,900 customer transactions
- **Total Features:** 18 columns
- **Data Type:** Customer shopping and transaction data

### Key Dataset Features

- **Customer Information:** Age, Gender, Location, Subscription Status
- **Purchase Details:** Item Purchased, Category, Purchase Amount, Season, Size, Color
- **Shopping Behavior:** Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases
- **Customer Feedback:** Review Rating
- **Delivery Information:** Shipping Type

## 1. Jupyter Notebook – Python & Exploratory Data Analysis

Python was used to load, inspect, clean, transform, and explore the customer shopping dataset.

### Key Activities

- Imported the dataset into Jupyter Notebook using Pandas.
- Examined the dataset structure using `df.info()` and `df.describe()`.
- Identified and handled missing values.
- Filled 37 missing values in the Review Rating column using the median rating for the corresponding product category.
- Renamed columns using the snake_case naming convention.
- Created an `age_group` column by categorizing customers based on age.
- Created a `purchase_frequency_days` column from purchase frequency information.
- Examined the relationship between discount usage and promo code usage.
- Removed the redundant `promo_code_used` column after checking its relationship with `discount_applied`.
- Performed Exploratory Data Analysis to understand customer purchasing patterns.

### Libraries Used

### Outcome

A cleaned and structured dataset ready for database integration and further business analysis.

## 2. PostgreSQL – Database Management & SQL Analysis

PostgreSQL was used to store the cleaned dataset and perform SQL queries to answer business-related questions.

### Key Activities

- Connected Python to PostgreSQL.
- Loaded the cleaned dataset into a PostgreSQL database.
- Executed SQL queries to analyze customer behavior and purchasing trends.
- Used aggregate functions, filtering, grouping, joins, subqueries, and window functions to extract insights.

### Business Questions Explored

1. **Revenue by Gender:** Compared total revenue generated by male and female customers.
2. **High-Spending Discount Users:** Identified customers who used discounts but spent more than the average purchase amount.
3. **Top-Rated Products:** Identified the top five products based on average review ratings.
4. **Shipping Type Analysis:** Compared average purchase amounts between Standard and Express shipping.
5. **Subscription Analysis:** Compared average spending and total revenue between subscribers and non-subscribers.
6. **Discount-Dependent Products:** Identified five products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments based on purchase history.
8. **Top Products by Category:** Identified the top three most-purchased products within each category.
9. **Repeat Customer Analysis:** Analyzed customers with more than five previous purchases and their subscription likelihood.
10. **Revenue by Age Group:** Evaluated revenue contribution across different customer age groups.

### SQL Concepts Applied

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- CASE Statements
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- RANK(), DENSE_RANK(), and ROW_NUMBER()
- Conditional Aggregation

### Outcome

Extracted business-oriented insights from customer transaction data using PostgreSQL.
